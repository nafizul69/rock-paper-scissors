# 🎮 RoCk, Paper, Scissor — Pixel Battle

A pixel-art Rock Paper Scissors game that runs in any browser. No install, no sign-up.

**▶ Play now:** `https://nafizul69.github.io/pixel-rps/`  (live after you finish the steps below)

## ⚔️ Game modes
- **VS CPU** — pick your level: **EASY · MEDIUM · HARD · NORMAL**. HARD learns your habits, so mix up your moves!
- **ONLINE 1v1** — create a room, share the 5-letter code (WhatsApp / Telegram / Facebook / X), and battle a friend.
- **🎤 Voice chat** in online matches, **😂😭😡😍😈🤑 emoji reactions with sound**, and **sparkle VICTORY / DEFEAT** banners.
- **Choose your hand color**, **challenges** (with a SKIP button), and **regions**: 🇧🇩 Bangladesh and 🇮🇳 India historical-place battlegrounds.

## 🎨 Assets
All sprites are exported as PNG in [`assets/`](assets/): hands, emoji, sparkles, Victory/Defeat ribbons.

## 🌍 Languages
English · বাংলা · Español · Français  (in Bangla mode, hit the **হাল্লা বল** bar to start with a battle cry!)

## 🕹️ Controls
Tap a hand, or press **1** (Rock), **2** (Paper), **3** (Scissors).

## 📦 Run it yourself
Download `index.html` and open it. Online play and voice chat need the internet (and https for the mic — GitHub Pages gives you that).

## 🚀 Publish with GitHub Pages (free)
1. Create a GitHub account → **New repository** → name it `pixel-rps` → Public.
2. **Add file → Upload files** → upload `index.html`, `README.md`, `.nojekyll` → **Commit**.
3. **Settings → Pages → Branch: `main` / `(root)` → Save.** After ~1 minute your game is live at the link above.
